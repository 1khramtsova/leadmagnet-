# LP «50 prompts de IA para quem vende na Shopee»

Страница захвата под лончевую воронку Shopee: партнёры ведут трафик из сторис → человек
оставляет контакты → получает лид-магнит (50 промптов под Shopee).

| Что | Где |
|---|---|
| Сама страница | `50-prompts-shopee/index.html` |
| Картинки страницы | `50-prompts-shopee/assets/` |
| Обработчик формы | `api/lead.js` |
| Адрес после деплоя | `https://br.joompulse.net/50-prompts-shopee` |

Сборки нет: обычный HTML + CSS + JS. Пушим в `main` — Vercel сам раскладывает
`<папка>/index.html` по адресу `/<папка>`, а всё из `api/` превращает в серверные функции.

---

## 1. Как работает форма

Поля, которые видит человек: имя, телефон (+55), e-mail, «Onde você vende hoje?»,
«Qual é o faturamento mensal?», чекбокс согласия.

Кроме них форма отправляет **скрытые поля** (в HTML это `<input type="hidden">`,
блок помечен комментарием «campos ocultos»):

| Поле | Значение |
|---|---|
| `leadmagnet` | `leadmagnet-50-prompts-shopee` — зашито в странице, это и есть та самая переменная |
| `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `partner` | подставляются **из ссылки**, по которой пришёл человек |
| `page_url`, `referrer` | адрес страницы и откуда пришёл |

UTM-ки запоминаются в сессии браузера: даже если человек полистает страницу и вернётся
без параметров в адресе, метка партнёра не потеряется. Это важно для комиссии по UTM.

Ссылка для партнёра выглядит так:

```
https://br.joompulse.net/50-prompts-shopee?utm_source=organic&utm_medium=igstories&utm_campaign=lancamento-shopee&partner=NOME_DO_PARCEIRO
```

Каждому партнёру — свой `partner` / `utm_source`, больше ничего настраивать не нужно.

**Чтобы завести такой же лид-магнит под другой оффер**: скопируйте папку, поменяйте тексты
и одно значение — `value="leadmagnet-..."` в скрытом поле `leadmagnet`. Всё остальное общее.

## 2. Куда падают заявки

Сейчас `api/lead.js` работает как **заглушка**: проверяет заявку, пишет её в лог Vercel
и отвечает «ок» (человека дальше редиректит на материал).

Посмотреть заявки: Vercel → проект `leadmagnet` → **Logs** (Runtime Logs), фильтр по слову `[lead]`.

### Как включить реальную отправку — без правок кода

Vercel → проект `leadmagnet` → **Settings → Environment Variables** → Add:

| Name | Value | Обязательна? |
|---|---|---|
| `LEAD_WEBHOOK_URL` | URL вебхука Albato / Kommo / Make / n8n | да, чтобы лиды уходили |
| `LEAD_WEBHOOK_TOKEN` | токен, если ручка его требует (уйдёт в `Authorization: Bearer …`) | нет |
| `LEAD_REDIRECT_URL` | куда вести человека после отправки | нет |

Environment: отметьте **Production** (и Preview, если хотите проверять на превью-ссылках).

⚠️ **Переменные подхватываются только при новом деплое.** После добавления: Deployments →
последний деплой → «…» → **Redeploy**. Ничего в коде трогать не надо.

Почему так, а не URL прямо в странице: ключи и адреса ручек не должны лежать в HTML —
их видно всем, кто откроет страницу. Серверная функция `api/lead.js` выполняется на стороне
Vercel, поэтому переменные окружения остаются приватными.

Заявка уходит в вебхук как JSON — теми же именами полей, что в таблице выше, плюс
`recebido_em` (время). Если вебхук лежит — заявка всё равно остаётся в логе, и человек
всё равно получает материал.

## 3. Что можно поменять прямо в странице

В конце `index.html` есть блок `var CONFIG = { … }`:

* `redirectUrl` — куда ведём после отправки формы. Сейчас `/prompts-shopee` (страница с 50
  промптами). Переменная `LEAD_REDIRECT_URL` на Vercel перебивает это значение.
* `privacyUrl` — ссылка на политику конфиденциальности (в чекбоксе и в подвале).
* `endpoint` — куда шлётся форма, `/api/lead`. Менять не нужно.

Тексты, карточки блока «O que tem dentro do cofre» и кнопки правятся прямо в HTML —
это обычная разметка, без шаблонизаторов.

## 4. Как проверить локально

```bash
python3 -m http.server 8000      # из корня репозитория
open http://localhost:8000/50-prompts-shopee/
```

Так проверяется вёрстка и вся логика формы, кроме `api/lead.js` (локально его нет —
форма покажет «Не деу пра энвиар»). Отправку целиком проще проверить на превью-деплое Vercel.
